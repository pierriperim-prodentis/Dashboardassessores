# Relatório ARP 2025 vs 2026

Dashboard comparativo de vendas Pródentis/ARP.

## Como subir no Streamlit

1. Crie um repositório no GitHub chamado `relatorio-arp`
2. Faça upload de todos esses arquivos para o repositório
3. Acesse https://share.streamlit.io
4. Clique em "New app"
5. Selecione seu repositório `relatorio-arp`
6. Branch: `main`
7. Main file: `app.py`
8. Clique em "Deploy"

Pronto! O link será algo como:
`https://seu-usuario-relatorio-arp.streamlit.app`
